# prosamik-motion

Public motion-graphics pages for the private `prosamik-videos` repo. One folder per video, named `<issue>-<slug>` like the private repo's `docs/motion/` folder.

Published with GitHub Pages: https://prosamik.github.io/prosamik-motion/

Open a page, press Space to step through the scenes, R to restart. Add `?bg=green` for a green background you can key out.

Only the HTML/CSS/JS for these pages lives here. Add new motion pages here and link them back from the matching issue in the private repo.
